# Jellyfin + Telerising + EasyEPG DockerPack for UGREEN NAS

Download the English ZIP (`*_en.zip`) from the [latest release](https://github.com/Railsimulatornet/UGREEN-NAS-Jellyfin-Telerising-EasyEPG-DockerPack/releases/latest).
Extract it into your Docker directory, for example `/volume2/docker/`; the project is then in `JellyfinServer/`.

The [German README](README.md) is the primary documentation.  
English manuals are included under `v1/en/`.
